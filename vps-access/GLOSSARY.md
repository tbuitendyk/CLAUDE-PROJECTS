# Glossary — the fixed vocabulary (owner-ordered, 2026-08-01)

One term per thing, forever. Any new term is added HERE with a plain
definition before it is used in any email, table, screen or report.
Renaming an existing concept is forbidden; if a better word is ever
wanted, the owner approves the change and the old word is listed as
retired.

| Term | Means exactly |
|---|---|
| member | one of the six models (three data views x two learner types) |
| committee | the six members working on one setup |
| vote | one member's call on one chunk: up, down, or stand aside |
| agreement level | how many of the six must concur before a trade happens |
| chunk | one bite of history a member reads (1-4 days of data) |
| setup | one coin + one chunk length + one voting style; there are 136 |
| voting style | how a member forms its vote: most-likely-wins or direction-hunter |
| fold | one step of the walk: train on the past, pick dials on the test window, score once on the holdout window; ~25-45 folds per setup |
| train window | the past the members learn from |
| test window | the 8 weeks where dial combinations audition |
| holdout window | the next 8 weeks, unseen — the only money that counts |
| dial combination | one complete choice of the five trade dials (entry method, gate, tripwire distance, time limit, agreement level) |
| the menu | the list of all possible dial combinations |
| luck committee | the scrambled-votes twin of the system — the judge of skill |
| always-long line | the tide gauge: going long every slot, comparison only |
| board | the results table, one row per setup |

Retired words (never use again): "recipe" / "trade recipe" and "cell"
(-> dial combination); "experiment" (-> setup); "stretch" / "slice"
(-> window); "null arm" in owner-facing text (-> luck committee);
"quorum" in owner-facing text (-> agreement level).
