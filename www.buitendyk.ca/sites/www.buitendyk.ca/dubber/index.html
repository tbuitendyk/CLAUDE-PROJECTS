Spanish Video Dubber

Give it an English-language YouTube video and it generates a Spanish voice-over — from existing captions, an auto-generated transcript, or a fresh transcription — then publishes it to the connected channel. See how it works in the project README.

Checking access…

Submitting a dub publishes a real video to a real YouTube channel, so this action is locked behind the same site credentials used elsewhere on buitendyk.ca. Sign in to enable the button below.

The destination YouTube channel is fixed: it's whichever channel was authorized when the dubber service ran its one-time YouTube sign-in on the server (see the project README's "YouTube authorization" step).

Preview thumbnail fetches just the video's thumbnail (no full download) and shows it next to a Spanish version — the text baked into the image is detected and translated, with the “Versión Español” banner added on top. Correct any line and Save: saved thumbnails live with the project in the library and are used automatically when you dub.

Preview transcript first runs just the cheap diagnostic stages — fetching or transcribing the original-language text, then translating it — and opens both side by side below. Each Spanish line is editable; Save stores it as the project's draft in the library (so it survives reloads), and Start dubbing speaks the saved draft verbatim.

Pick one of your published dubs, choose where the new thumbnail comes from, edit the detected text, and apply it — no re-dub needed.

One entry per video and language — drafts and published dubs alike. Open one to read or fix its transcript (the original-language text is kept forever), redub it after edits, or delete it for good.

Restart the dubbing service — frees its memory and stops any job that's currently running. Queued jobs are kept and resume afterward.

Diagnose extraction

Probe YouTube extraction and capture the full verbose trace — why downloads are (or aren't) getting real formats. Uses the source URL above if set, otherwise a sample video.
