Spanish Video Dubber

Give it an English-language YouTube video; it produces a Spanish voice-over (from an existing transcript, an auto-generated one, or a freshly transcribed one) and publishes the result to the channel this service is authorized for. See how it works in the project README.

Checking access…

Submitting a dub publishes a real video to a real YouTube channel, so this action is locked behind the same site credentials used elsewhere on buitendyk.ca. Sign in to enable the button below.

New video dubbing project

The destination YouTube channel is fixed: it's whichever channel was authorized when the dubber service ran its one-time YouTube sign-in on the server (see the project README's "YouTube authorization" step).

Preview thumbnail fetches just the video's thumbnail (no full download) and shows it next to a Spanish version — the text baked into the image is detected and translated, with the “Versión Español” banner added on top. You can correct any translated line and, once it looks right, mark it to be used for the upload. It's optional: skip it and the dub generates one automatically.

Not sure the result will sound right? Preview transcript first runs just the cheap diagnostic stages — fetching or transcribing the original-language text, then translating it — and shows both side by side, line by line, so you can tell whether a problem is in the transcription or the translation before spending the time on a full narration/upload run. Each Spanish line is editable: tweak it and hit its Save button, and if you then click Start dubbing for the same video, the dub will speak your saved lines verbatim instead of retranslating from scratch.

Update an existing video's thumbnail

Generate a Spanish thumbnail from the English source video URL above and apply it to a video already published on the connected channel — no re-dub needed. Same detect-translate-and-edit step as the dub thumbnail; the result is pushed straight to the target video.

Redub completed project

Re-dub one of your own finished videos from a saved transcript — recreates the spoken track in the same language over the original music & sound effects, and uploads it as a new video. Need to correct a line first? Fix it in the Transcripts library below, then redub.

Transcripts library

Every dubbed video keeps its timestamped transcript here. Open one to read it, fix any line and save (then redub above to apply), or download it.

Control dubbing service

Restart the dubbing service — frees its memory and stops any job that's currently running. Queued jobs are kept and resume afterward.
