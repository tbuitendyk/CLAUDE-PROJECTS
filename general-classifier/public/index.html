General Classifier

Trains a classifier on weekly 8-day chunks of hourly Binance data (Mon 00:00 → Mon 23:59 UTC, both pairs), scored by the trade pair's move from the following Tuesday morning (00:00–05:59) to that week's Thursday afternoon (12:00–17:59): 0 inside the dormant band, else +1 up / −1 down. First 80% of weeks train, most recent 20% test — all math runs locally on this server, no AI involved.

Live tracker (paper)

Frozen DOT/AVAX consensus models (trained through 2026-06, never retrained) predict every week's Tue→Thu move and paper-trade it: $100 per order, entry Tue 03:00 open, exit Thu 15:00 open, $0.50 friction per leg. Majority vote of the 8 specs is the headline book; ties stand aside. Every post-June week is unseen data — the frozen models never trained on any of it. Weeks recorded before their outcome window (Thu 12:00 UTC) count as LIVE toward the 26-week verdict; the backfill is labeled unseen and reported alongside. Protocol + amendment log: TRACKER.md in the repo.

Pair screen (batch)

Runs the full pipeline for a fixed list of high-cap, long-history pairs against BTCUSDT, with both models, using the dormant range / months / features set above. Results persist on the server; the table ranks combos by edge over the majority baseline.

The consensus screen runs a FIXED spec grid per pair — 4 feature views (full / prices / volume / cross-asset) × 2 models, adaptive band, full history above — and scores each pair by agreement across its 8 specs, never by its best cell. Each pair also gets a simulated vote book: every test period the 8 specs vote (majority wins, ties stand aside — the live tracker's exact rule) and the vote trades $100 at the geometry's entry/exit candles, so the screen reports the dollars the actual consensus strategy would have made. Null shifts re-run the whole grid with circularly time-shifted labels to measure the noise floor (expensive: each shift adds 8 more runs per pair — use a short pair list). Note: a pair only has ~(weeks − 16) distinct rotations (≈290 for a 2020-listed pair, ≈420 for full history), so requests beyond that hit duplicate rotations, which are collapsed into single null samples rather than double-counted — the exceed-rate denominator shows the true distinct count. All work obeys the CPU cap.

Data: Binance public bulk-data portal (data.binance.vision), hourly spot klines, pruned to time / open / high / low / close / quote volume.
