General Classifier

Trains a classifier on weekly 8-day chunks of hourly Binance data (Mon 00:00 → Mon 23:59 UTC, both pairs), scored by the trade pair's move from the following Tuesday morning (00:00–05:59) to that week's Thursday afternoon (12:00–17:59): 0 inside the dormant band, else +1 up / −1 down. First 80% of weeks train, most recent 20% test — all math runs locally on this server, no AI involved.

Bracket lab lab guide

Sweeps asset combos (a trade asset alone, or with one or two context assets) × any permuted options × the full OCO bracket execution menu (one-cancels-the-other: a profit target and a tripwire placed together; whichever price touches first executes and cancels the other; the time limit closes whatever remains). Slim grid first, top combos promoted to the full committee (6 members for singles, 8 with context assets) with every agreement level. Selection is mechanical (best net $, min-trade floor) and every menu is stamped. The window layout is chosen explicitly — 80/20, 70/15/15, or 61/13/13/13 with the final 13% sealed. Null tests live below the survivor board, each stating which layer of chance it prices. Ambiguous hourly bars always resolve AGAINST the book and are counted.

Live tracker (paper)

Frozen DOT/AVAX consensus models (trained through 2026-06, never retrained) predict every week's Tue→Thu move and paper-trade it: $100 per order, entry Tue 03:00 open, exit Thu 15:00 open, $0.50 friction per leg. Majority vote of the 8 specs is the headline book; ties stand aside. Every post-June week is unseen data — the frozen models never trained on any of it. Weeks recorded before their outcome window (Thu 12:00 UTC) count as LIVE toward the 26-week verdict; the backfill is labeled unseen and reported alongside. Protocol + amendment log: TRACKER.md in the repo.

Live tracker II — DOGE daily-3d (paper)

A second, independent book. Frozen 8-spec models (trained through 2026-06, never retrained) predict every day's 41-hour move: entry 01:00 UTC the day after the 72-hour chunk closes, exit 18:00 the following day, $100 per order, $0.50 per leg. Five decision rules are declared in advance and all five are reported — the majority vote plus the agreement gradient at 5, 6, 7 and 8 of 8 — so nothing is selected after the fact and no multiplicity correction is owed. Backtest gradient to beat: win rate 53.7% / 57.4% / 62.6% / 67.3% across the four quorums. Positions overlap (a signal a day against a 41-hour hold), so implied capital is ~$200–300, not $100. Protocol: TRACKER-DOGE.md in the repo.

Screens (batch)

Three instruments, all persisting to the server and readable in the picker below. Quick screen (legacy): 17 pairs × 2 models, one spec each, full view only — the original pre-consensus screen. Cheap pulse-check (34 runs) and the only screen that honors the raw-features option, but it has no feature views, no vote/gate books and NO null support: never a basis for belief. Consensus and meta-lens (protocol selector below) are the real instruments — spec grids, vote and gate books, gradients, and null calibration.

The consensus screen runs a FIXED spec grid per pair — 4 feature views (full / prices / volume / cross-asset) × 2 models, adaptive band, full history above — and scores each pair by agreement across its 8 specs, never by its best cell. Each pair also gets a simulated vote book: every test period the 8 specs vote (majority wins, ties stand aside — the live tracker's exact rule) and the vote trades $100 at the geometry's entry/exit candles, so the screen reports the dollars the actual consensus strategy would have made — plus a super 6/8 book that trades only when six or more specs call the same direction, the conviction-concentration gate aimed at fee drag. Null shifts re-run the whole grid with circularly time-shifted labels to measure the noise floor (expensive: each shift adds 8 more runs per pair — use a short pair list). Note: a pair only has ~(weeks − 16) distinct rotations (≈290 for a 2020-listed pair, ≈420 for full history), so requests beyond that hit duplicate rotations, which are collapsed into single null samples rather than double-counted — the exceed-rate denominator shows the true distinct count. All work obeys the CPU cap.

Data: Binance public bulk-data portal (data.binance.vision), hourly spot klines, pruned to time / open / high / low / close / quote volume.
