The Bracket lab, component by component

This page walks the lab in the order it appears on screen. Every component says why it exists, how to use it, when to use it — and what it can NOT tell you. The recommended workflow in one line: load data → board sweep → null boards → two reads → (optional) History Tuning → replication → paper book. Money claims only ever come from the end of that chain.

1 — The sweep form

form Universe · combo sizes · permuted options · execution menu · window layout ▾ · min trades · Start sweep

↑ The window layout dropdown is the decision that shapes every number downstream.

Why: the wide pass — every setup (coin × chunk shape × decision style) against the whole execution menu. Its output is a DIRECTION (promising rows), never a result. The three layouts:

  • 70/15/15 — train on the oldest 70%, pick the trade settings in the next 15% (the test window), grade the pick once on the newest 15% (the hold window). The standard.
  • legacy 80/20 — nothing held back. A coarse look; rows from it can never be evidence and never qualify for History Tuning.
  • 61/13/13/13 — the 70/15/15 treatment on the first 87% of history, with the final 13% SEALED: this run never touches it. It exists so a History Tuning winner can later take a one-touch final exam on data nothing ever shopped on. Cost: the board trains on slightly less and picks on slightly older windows — the honest price of a sealed exam.

Null boards: set the null-board count on the form and the sweep ships with companion boards whose members trained on real data but had their votes dealt onto random days (each member's real mix of up/down/stand-aside, dates destroyed). Those boards feed Tool 2 below.

2 — The job header

header job id — status · description · settings table: every setting that shapes the result — window layout, outcomes, execution grid, fees, floors

Why: a number whose settings are invisible is a number you cannot trust. The rule for this table: every setting that shapes the result, on the page — including the window layout. If a setting is missing here, that is a defect; say so.

3 — The survivor board

board setup · q · gate/entry · TEST WINDOW (chosen on — flattering) · HELD-BACK (what matters) — e.g. active/breakout, directional/market

↑ gate first, then entry — no entry without the gate passing. Cells match the header format exactly.

Reading it: the TEST columns are where each row's settings were CHOSEN — the best of many tries, flattering by construction. The HELD-BACK columns were scored once with settings already committed; they are the only honest columns on the board. The gates: always = votes ignored (baseline only, never tunable); active = the committee decides WHEN to trade, price decides the direction; directional = the committee decides when AND which way.

4 — Null tests (two tools, two layers of chance)

tool 1 This row against its null runs — fires N null rounds
tool 2 The board against a null board — reads stored boards, fires nothing

Why two: a good number can arise without signal from the shopping INSIDE one row (menu × agreement levels, best kept), and separately from PICKING the best row off a board of many. Tool 1 prices the first (hundreds of dealt-vote rounds on one row — fine resolution, blind to the board layer). Tool 2 prices the second (the real board's best vs a null board's best — the reading that matters for any row you picked off a board; resolution limited by the null-board count and printed). A row worth acting on passes both. Both use the dealt-votes construction: real vote mix, zero date knowledge; the label-rotation construction was retired after it was shown to leak market knowledge.

5 — History Tuning (optional second pass)

panel select a survivor → History Tuning activates (or says in words why not) → 105 passes → dial-pair board → null draws → reserve grade (one touch, final)

Why: a survivor was measured under fixed assumptions about how much history matters. This tunes two dials for that one setup: the age half-life (how strongly old training data fades — members retrained at every half-life milestone counted from the start of history) and the retune cadence (how often the five trade variables — agreement level, gate, entry, tripwire distance, time limit — are re-picked on recent results). The untuned reference pass runs first so "did tuning beat not tuning" always has an answer. Picking happens on test windows only; holds are graded once; four reading rules are stamped into the run before anything computes and the verdict prints through them. When: only on rows that passed both null tests, and only when the setup deserves the investment — this is hours of compute. The reserve grade: if the setup's board run used the 61/13/13/13 layout, one button fires the winner + reference + 19 null draws over the sealed reserve as ONE verification event, ever. A failed reserve is a dead end, never a hint.

6 — Inside a setup (microscope)

inspect one row's committee: each member's model, votes, solo score

Why: to understand WHY a row behaves as it does before spending null tests on it. Never evidence: nothing here is out-of-sample.

7 — Compare two runs

compare run A vs run B → every differing setting listed first → shared rows paired → ATTRIBUTABLE stamp only at exactly one difference

Why: "did this one change help?" needs paired reading with the differences named. The honesty rule is the one-variable rule as a tool: money differences prove something only when exactly one setting differs; with more, the comparison shows but is stamped not-attributable.

The paths compared — what each can claim

Sweep and look. You get a board and its flattering test columns. Claim earned: "here is a direction worth checking." Nothing more — not even from the held-back column, because you looked at 170 of them.
Sweep + null boards + both reads. Rows that pass both are survivors: their numbers exceed what informationless votes produced through the same machinery, inside the row and across the board. Claim earned: "worth tuning, worth replicating." Still not "it works."
The full chain: + History Tuning + its nulls + reserve grade (or paper book) + replication. The winner beat the untuned reference under stamped rules, no null draw matched it, and it repeated somewhere it was never selected. Claim earned: "this works, within the resolution floors printed on its record." This is the only path that earns that sentence — and the forward paper book remains the final word.
