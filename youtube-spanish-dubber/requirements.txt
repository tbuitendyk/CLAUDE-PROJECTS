# YouTube download + caption retrieval
# Unlike the other deps below, this one is intentionally NOT pinned to an exact
# version: YouTube frequently changes its player/signature internals, and
# yt-dlp ships frequent point releases purely to keep extraction working.
# An exact pin here goes stale within weeks and starts failing with errors
# like "Requested format is not available" / "nsig extraction failed". Always
# install/upgrade to the latest: pip install -U yt-dlp
yt-dlp>=2024.12.13

# wheels. The two small language models (~13-15 MB each) are pinned to 3.8.x to
# stay compatible with the spaCy range below; the rechunker degrades to
# punctuation-only boundaries if a model is ever missing.
