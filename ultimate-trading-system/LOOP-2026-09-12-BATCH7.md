## The success rule for each step, written before it is built

- **S5 — the 13%.** PASS when `grep -c '0\.13'` over `lib/` returns exactly ONE
  place that owns the share, every other reader calls it, and the full suite is
  green with not one number moved. FAIL if any behaviour changes at all: this
  step is a consolidation and a changed number means it was not one.
- **S7 — the test window.** PASS when the window comes off the record's own
  stored range and the reconstruction is DELETED, not patched. The check that
  matters: on a record carrying `windows.test`, the reported window equals that
  stored range exactly — not approximately. FAIL if a fallback to the old
  arithmetic survives anywhere (RULE NINE: no legacy branch), or if I cannot
  confirm the units at that call site carry the ranges, in which case it is
  PARKED with what I found rather than guessed at.
- **S4 — the ceiling as a control.** PASS when the value is set on screen,
  travels to the training, is written on the record, and the figure the Coins
  screen quotes MOVES when it is changed. FAIL if the Coins figure stays at
  1.7% whatever the control says, because then the two are not the same number.
- **S6 — the two weight readings.** PASS when the biggest weight BEFORE capping
  and the count of chunks held at the ceiling are both worked out, both stored,
  and both on screen, and when a run with the ceiling off reports a biggest that
  is larger than the ceiling a capped run reports. FAIL if either number can only
  ever read at or below the ceiling, which is the exact fault being fixed.
- **S2 — the too-little-history warning.** PASS when the line is worked out from
  the coin's own periods with nothing typed, when a coin of 40 periods with no
  trend raises it, and when a coin of 2,000 periods with a real one-way run does
  NOT. FAIL if a threshold appears as a literal anywhere, or if it refuses a
  coin rather than warning about one (COINS.md section 8).
- **S1 — the word list.** PASS when regenerating adds exactly three entries,
  all `24/5`, and nothing else anywhere in the file. FAIL on any fourth
  addition: the measurement said three and a fourth means the rule is wider than
  what was approved.
