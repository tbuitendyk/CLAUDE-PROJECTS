1. What this tool is

A semi-automatic rebalancer: it watches your portfolio (one flat pool of assets per profile), and when an asset drifts far enough from its target weight it notifies you with the exact trades to make. Nothing trades itself, and nothing changes settings itself — every analysis is advisory-with-apply. The two in-page analysis tools (tuner and lab) are backtests over real exchange history (~4 years daily where available), with honesty rails: costs always on, out-of-sample confirmation, and explicit "no edge found" verdicts. The Ladder Lab (header button, opens its own page) is a separate BTC/USD strategy laboratory with live rung monitors; sub-accounts let several profiles trade independently inside one exchange account for small real-allocation trials.

2. Assets grid & the tethered index

  • Index checkbox — exactly one asset is the tethered index (USDC, USD, MXN…). Every value, basket and backtest is denominated in it. Switching it splices the track record continuously — then use Set new targets to give the new tether a real band.
  • Trigger @ — the per-asset drift trigger, derived from the profile sensitivity X by weight-normalization X(1−w)/(1+wX), so a 4% asset and a 56% asset both react at about the same own-price move. The tether itself never trades on its own breach.
  • Status — the buy-freeze badge (click to unfreeze), the standing ignore freeze toggle (visible on every active asset, persists across freeze/unfreeze), and the depeg flag. See Safety rails.

3. Targets, basket & value index

Set new targets opens the editor; targets (index included) must total 100%. Two chained series survive every change:

  • Currency basket — unit growth from trading only. Deposits, withdrawals and target changes splice through it without a jump; only buys/sells (and market moves between them) move it. Basket > 1.0 means rebalancing has accumulated units.
  • Value index — performance in index-currency terms since value started; feeds the annualized (compounding) rate on the profile summary.

Record manual deposits / withdrawals in their section (or let exchange sync detect them) — they are spliced, never counted as gains.

4. Sensitivity tuner (backtest)

  • Basket / Value / vs hold — whole-window results per X; vs hold is the harvest edge over doing nothing. A recommendation appears only where basket AND value agree on a plateau; divergence gives a warning instead.
  • ½ recent / ¼ recent — the same X over the most recent half and quarter of the history, each against its own hold baseline. An X that shines on all-history but bleeds in the recent quarter is an edge that died.
  • Hypothetical sweeps — arriving via ⇢ tuner from the lab, the exact mix under test is shown above the table and Apply is disabled (it's not your applied targets). The stamp says HYPOTHETICAL.
  • Idealize tether 1:1 — assumption toggle: treat a USD-stable tether as a perfect $1 peg (erases real wobble/depegs, e.g. USDC's 2023 SVB dip). Stated in the stamp when on; refuses non-USD-stable tethers.

5. Composition lab (mix search)

Scopes

  • Full universe — your holdings + top market-cap candidates (venue-tradable, full-window history), searching groups AND weights. Mixes range from a single tradable asset (tether + one coin taking 75–90%) up to 8; the per-asset cap scales with the count — 25% at 4+ assets, wider for concentrated mixes (a pair splits within 2.5–45%).
  • Current holdings — re-weight only — your exact asset set, nothing added or dropped; each asset 4–80% on a 1% grid; every split carries its own split × sensitivity strip (per-X edge, best X starred — trust runs of green, not a lone starred spike).
  • Current holdings — allow drops — subsets + weights of what you own, so dead weight can be shed.

How to read a result

  • Two modes. With deep history the search runs regime mode (columns above: per-market-type harvest, classified from BTC's action into bull/bear/range swaths). With shallow history it runs folds mode (walk-forward: Folds ✓ / Median edge columns).
  • Harvest edge ≠ return. Bull/Bear/Range/Worst/Avg measure what rebalancing added over holding the same bag — blind to whether the bag itself sank. That's why the quality gate exists:
  • ✓mkt / ▼mkt — does the mix keep up with the market (holding BTC in your index currency) on return AND drawdown? ★ requires harvesting and ✓mkt with a positive holdout. Mixes that harvested well but sank are hidden (counted in the stamp).
  • No-harvest / no-real-possibility verdicts — when nothing clears the bar the table says so honestly instead of dressing up the least-bad row.
  • The stamp (bottom line) records everything: combos searched, universe and every exclusion by name (venue, missing history, your pool unchecks), window and what limited it, regime day-counts, the market bar, and any active assumptions.
  • Cancel — while a search runs, the Cancel button next to Run search stops it within seconds ("cancelled — no result saved"); your last completed result stays untouched.

6. Candidate pool (exclusions)

Candidate pool… (next to Run search) lists everything the lab would consider — held assets (marked •) and market candidates. Uncheck an asset to exclude it from every scope; saved per profile instantly, and named in the result stamp ("excluded by you: …"). The tethered index is locked — every mix is denominated in it. Use this to weed assets that are expensive to trade from your position (indirect crosses) or that you never want proposed.

7. Ladder Lab (BTC/USD)

Its own page (Ladder Lab header button, opens a new tab): a two-asset USD+BTC strategy laboratory for the cycle-ladder thesis — buy rungs on drawdowns from the all-time high, sell rungs into strength anchored to the high you fell from, with order sizing, a hard USD reserve floor, and optional monthly DCA.

  • Data — one button loads the deepest daily BTC/USD history available (Binance archive reaches 2017-08, ~9 years).
  • Sweep — every configuration in the 78,732-point grid (entry rungs × spacing × count × buy sizing × exit levels × spacing × count × sell sizing × reserve × DCA) is scored on the FULL history — deliberately no holdout; the synthetic-futures grid is the forward test instead, and the caveat renders with every result. Score = MAR (CAGR ÷ max drawdown).
  • Plateaus & picks — each config's robust score is the worst MAR among itself and all one-step neighbors; connected high-robust regions are the plateaus. Picks are each plateau's best member plus the best per risk tier (max DD <30 / 30–50 / >50%), every row stating its plateau standing and carrying generated reasoning underneath.
  • Epoch mechanics — a new ATH re-arms the entry ladder; the first entry of an epoch arms the exit ladder at absolute multiples of that epoch's peak, which stay armed until hit even across later highs (ladder memory — unlike weight-based rebalancing).
  • Synthetic futures — every pick is projected across 8 archetypes (steady bull, moonshot-crash, plummet-flat, crash-recover, crab, bull-bear, double cycle, history bootstrap) × 60 five-year paths starting at today's price with the real ATH carried in. Rough probabilities come from 2,000 history bootstraps — labeled rough; short history can't price structural change.
  • Adopt as monitor — every pick row can become a live monitor in one click (next section).

8. Ladder monitors

Live watching of an adopted ladder config (Ladder Lab page → Live monitors). The monitor checks the BTC price on its own cadence and notifies on rung crossings — buy rungs, anchored sell rungs, ladder re-anchor at a new ATH, and a monthly DCA reminder — by email and/or Telegram per its own recipients list (same rules as profile notifications). Rung chips on the card show fired (struck-through), armed, and next-up levels; alerts are one-shot per rung per epoch. Advisory only — it says what the config would do; the order is yours.

  • Real balances (optional) — enter your current USD, BTC, and the average cost of that BTC at setup, and every alert speaks in real amounts ("spend ≈ $2,000 ≈ 0.0266 BTC", "sell ≈ 0.0143 BTC ≈ $1,430, +43% vs your avg cost"), tracked forward by a modeled ledger using the lab's 0.5%/leg costs. Buys re-weight avg cost; sells don't. Leave empty for percent-only alerts.
  • Edit balances — true the model up after real fills any time; rung state is untouched.
  • Check now / Test alert — force an immediate evaluation; send a test through the full comms path before trusting it.

9. Exchange sync

Link a read-only API key (Kraken or Bitso). Balances and trades sync automatically; your quantities become ground truth from the venue. Detected deposits/withdrawals wait for confirmation before splicing the track record (auto-apply once you trust it). Real fills also calibrate the fee/spread costs the backtests use. The sync note warns when the key lacks history permissions.

10. Sub-accounts & small real-allocation trials

Several profiles can share ONE physical exchange account, each trading on its own alerts and tracking its own splice-continuous performance — the way to trial a lab mix with a small slice instead of the whole account. Found in the Exchange sync section once an account is linked.

  • The shell ("Unallocated") — linking a second profile creates it automatically: the visible pool of assets not assigned to any strategy. Physical balance = sum of strategy profiles + shell, exactly. Dust corrections land here, unattributable deposits default here, new trials are funded from here — strategy track records never absorb anything they didn't earn. It has no targets and no alerts; it's a wallet view, not a strategy.
  • Carve out — the virtual transfer that starts a trial: move amounts between linked profiles at live prices. No real trade happens and both track records splice past it — the source doesn't register a loss, the trial starts honest at day zero.
  • Fill attribution — synced fills resolve in three tiers: an asset held by exactly one linked profile attributes automatically; a fill matching a profile's own recent advice (same symbol+side, size ±15%, within 36h) attributes to it; anything ambiguous waits in the attribution inbox with the best guess pre-selected and a stated reason. A queued fill applies nothing until you assign it. The tether leg always follows the traded asset's profile.
  • Reconcile table — per asset: physical (venue truth) vs Σ virtual vs pending vs queued, with the residual flagged when it exceeds tolerance. Never silently fixed.
  • Transaction log & Rewind — every applied transaction (auto or manual: fills, flows, carve-outs, snaps, adoptions) appears in plain words, newest first, each row rewindable once. Rewind reverses it (attributed fills return to the inbox); Reassign → rewinds and assigns to the right profile in one click. History is never edited — corrections append; a rewind reaching back across an already-chained daily snapshot annotates the affected profile visibly instead of falsifying its record.

11. Safety rails

  • Buy-freeze (🧊) — an asset in a structural break (deep drawdown beyond its recovered envelope, or falling far more than the market) has BUY alerts suppressed; sells still alert. Auto-unfreezes on recovery or catch-up; click the badge to unfreeze manually.
  • Ignore freeze — standing per-asset override (visible on every active asset): BUY alerts and lab eligibility stay active even if the rail freezes it. Persists across freeze/unfreeze cycles — the chip highlights when armed.
  • Depeg watch (⚠) — a stable asset trading outside its band is flagged; valuation stays pinned 1:1.

12. Notifications

Per-profile recipients: email and/or Telegram (one bot token shared app-wide; each recipient /starts the bot, then "Find chat IDs"). The state machine: armed → alert sent → notified (quiet) → re-armed by the next sync, a screenshot upload, "Poll now", or the 12-hour timeout. "Poll now" is the universal reset.

13. Glossary

Sensitivity X
The profile-wide price-move threshold (%). Weight-normalized per asset into its Trigger @.
Harvest edge
Value growth above holding the identical basket untouched — what rebalancing itself added, in percentage points.
Hold
The do-nothing baseline: same starting weights, no trades ever.
Holdout
The most recent ~20% of the window, never touched during search/optimization — the only true out-of-sample number.
In-sample
The first ~80%, where the search optimizes. Bull/Bear/Range columns are in-sample attribution.
Regime / swath
Contiguous bull, bear or range stretch of the market, classified from BTC's action (centered trend, no lag). "Types ✓ 3/3" = harvested in all three.
Worst / Avg
Worst market-type edge (consistency — the primary rank) and the equal-weighted mean across types.
Folds
Shallow-history alternative: N sequential walk-forward windows; Folds ✓ counts how many the mix harvested in.
✓mkt
Keeps up with the market benchmark — holding BTC in the index currency — on both return and max drawdown.
Max DD
Deepest peak-to-trough fall of portfolio value across the window.
Basket
Chained unit-growth series moved only by trading; splice-continuous across targets, flows, and index switches.
Idealize tether
Assumption toggle: a USD-stable tether treated as a perfect $1 peg. Always stated in the stamp when active.
MAR
CAGR ÷ max drawdown — return per unit of worst pain; the Ladder Lab's ranking score.
Robust score
A ladder config's worst MAR among itself and all one-step grid neighbors. High robust = a plateau member; a lucky spike scores near zero.
Anchor / epoch
The ATH the ladder measures from. A new ATH starts a new epoch (entries re-arm); the first entry of an epoch arms the exit ladder at absolute levels against that anchor.
Shell profile
The per-account "Unallocated" pool: physical balance = strategy profiles + shell. Absorbs dust, funds carve-outs, never a strategy.
Carve-out
A virtual transfer between linked profiles — paired flow splices at live prices, no real trade, both track records continuous.
Attribution
Deciding which linked profile owns a synced fill: unique holder → automatic; advice match (±15%, 36h) → automatic; ambiguous → inbox.
Rewind
One-click reversal of any applied transaction. Appends a compensating entry (history never edited); attributed fills return to the inbox; cross-snapshot corrections annotate the profile visibly.
