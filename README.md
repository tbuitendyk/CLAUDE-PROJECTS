# Claude Projects — `ultimate-trading-system` branch

One project per branch. This branch carries the **Ultimate Trading System**:
a self-hosted web tool for finding a rule for entering and exiting trades,
establishing that the rule is not luck, and then running it forward — on paper
first, and with real money on a machine the user controls.

The code and its documents live in
[`ultimate-trading-system/`](ultimate-trading-system/).

- [`CLAUDE.md`](CLAUDE.md) — the rules a session works under on this branch.
- [`ultimate-trading-system/README.md`](ultimate-trading-system/README.md) —
  what the system does and how it is laid out.
- `ultimate-trading-system/THIS-RELEASE.md` — the owner's numbered points for
  the current build-out.
- `ultimate-trading-system/ARCHIVE/` — closed documents, kept for reference,
  not current instruction.

Work is done on a session branch and merged back to `ultimate-trading-system`,
which is the branch the server deploys from.
