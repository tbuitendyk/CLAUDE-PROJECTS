# Claude Projects — `general-classifier` branch

One project per branch. This branch carries the **General Classifier**
(`general-classifier/`): a self-hosted web tool that trains a pure-JS
classifier on weekly 8-day chunks of Binance hourly data, scored by the
following Tuesday→Thursday move of the trade pair, and reports honest
out-of-sample correlation metrics.

See [`general-classifier/README.md`](general-classifier/README.md) for the
full spec, layout, and deployment notes; `CLAUDE.md` for session conventions.
