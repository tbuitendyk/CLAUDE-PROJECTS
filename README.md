# Claude Projects — `ultimate-trading-system` branch

One project per branch. This branch carries the **Ultimate Trading System**
(`ultimate-trading-system/`): a self-hosted web tool that trains a pure-JS
classifier on Binance hourly data. This is the commercial variant derived
from the general-classifier branch which takes setups from conception and
training to confirmed and committed for live market use.

This is the commercialization branch that supports multi-user and offloading
of work to user-specified compute platforms such as local, vps1, vps2, etc.

See [`ultimate-trading-system/README.md`](ultimate-trading-system/README.md) for the
full spec, layout, and deployment notes; `CLAUDE.md` for session conventions.
